# Administrationsidorna

Catalog of Admin pages (Confluence *Administrationsidorna*). These notes explain **what the page is for**. They do not authorise opening production cases or changing live data unless the user asked in this message.

| Page | Purpose |
| --- | --- |
| Administrera organisationer | Create/rename/delete organisations (system **Administrera systemet**) |
| Administrera text och bild | Platform texts/images the citizen sees |
| Aktivera/inaktivera e-tjänst | Take a service on/off |
| Ange öppettider för en e-tjänst | Opening hours |
| Forcera ärenden / signera som ombud | Sign or force a case as ombud |
| Frågor och svar | FAQ admin |
| Hantera behörigheter | Users/groups — [permissions.md](permissions.md) |
| Hantera dokument | Documents/templates |
| Importera och exportera e-tjänster | Test ↔ prod (zip). Import in test → **Redaktör** |
| Integrationslogg | Debug adapter/plugin calls (no citizen-case rummaging) |
| Menygrupper | Publish services/blanketter into menu groups |
| Permanent borttagning av ärenden | Hard-delete already soft-deleted cases (batch). Prefer this over the scheduled job for large batches |
| Publicera e-tjänst och/eller blankett | Publish into a menygrupp |
| Skicka in ärende som ombud | Run a service for a citizen |
| Statistik och rapporter | Excel / användningsmodul |
| Systemhändelser | System event log |
| Sök och ta bort invånare (personpost) | GDPR-style person search/delete |
| Ta bort e-tjänst i admin | Remove a service |
| Ändra organisation för en e-tjänst | Move service between organisations |
| Ändra texter i e-tjänster | Same text surface as **Redaktör** |

Publishing and menygrupper need systembehörighet **Publicera e-tjänster och blanketter**.
