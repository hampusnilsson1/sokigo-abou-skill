# Registermodulen

Confluence children: Beskrivning; Import och export; Redigera register; Koppla register och e-tjänst; Behörigheter för register; Text/värdeseparering; Fokuswebinar.

Known facts (from space overview + builder field docs):

- Registers feed dropdowns / mappings in e-tjänster.
- **Text/värde-separering** matches builder **Separera text och värde**.
- Import/export of register rows is a module feature (Sokigo enablement).
- Register rights are separate from e-tjänst roles — see Confluence *Behörigheter för register*.

Do not invent column types or the couple-UI. Open the matching child if the user is configuring a register.
